This Python program is a specialized tool designed for university students to calculate their Semester Grade Point Average (SGPA) and corresponding percentage. It features a structured approach to grade calculation, taking into account different assessment components for theory and practical subjects.Key FeaturesCustomizable Subject Credits: The program allows users to input specific credit values for each subject, ensuring the calculation matches their specific curriculum requirements.Comprehensive Grading Logic: It uses a standard grading scale (from $A+$ to $F$) where marks are converted into grade points (e.g., $90+ = 10$ points).Segmented Assessment Scaling: For theory subjects, the program automatically scales marks from different components to a 100-point scale:Internal Assessment: 30% weightage.Mid-Term Marks: Scaled from 50 down to 20% weightage.End-Semester Marks: Scaled from 100 down to 50% weightage.Dynamic Subject Handling:Theory vs. Practical: The program adjusts its prompts based on whether a subject is theory-based or practical/project-based.Optional Subjects: Includes logic to skip optional subjects (like "SPECIALIZATION") so they don't affect the total credit count if not taken.Input Validation: Includes a safety mechanism to prevent invalid inputs, such as negative numbers, non-numeric characters, or marks exceeding the maximum limit.How it WorksThe program iterates through a list of subjects, prompting the user for credits and marks for each. It then calculates the Credit Points for each subject using the formula:$$\text{Credit Points} = \text{Subject Credits} \times \text{Grade Point}$$Finally, it calculates the SGPA by dividing the total credit points by the total credits earned, then provides a percentage equivalent ($SGPA \times 10$).
